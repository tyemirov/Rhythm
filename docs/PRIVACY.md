# Flow Privacy

This draft describes the current Flow application.
Its public address is not yet configured.

Flow keeps resume notes, Wave History, and preferences on your Mac.
The application has no account, analytics, or cloud synchronization.
It does not send this information to a server.

Flow includes links to other Marco Polo Research Lab projects.
These links open websites in your default browser when you select them.
Flow sends no notes, History, preferences, or activity measurements with these links.
Each website controls its own data practices.

Flow keeps up to 90 days of completed History.
Each resume note can contain up to 2,000 characters.

Optional inactivity detection reads the elapsed time since input.
Flow does not record keystrokes, input content, window titles, or screenshots.
Quiet reading and thought can appear as inactivity.
You can turn this feature off in Settings.
Manual Pause and Continue remain available.

Flow requests notification permission only when you click Enable reminders.
Notification delivery follows your macOS settings.
Optional chimes play through your current audio output.
Flow does not change macOS Focus automatically.

The microphone button shows Dictation instructions.
Flow does not capture microphone audio.
If you use macOS Dictation, Apple controls that service through your system settings.

If you send a support email, the recipient receives the information you include.
Send privacy questions to support@mprlab.com.
